# v0.5.1 patch plan

Status: completed

Web App Security Skill v0.5.1 is a compatibility patch for independently reproduced v0.5.0
audit findings. It does not add detection rules, change finding/report schemas, widen active network
behavior, or promote syntax matches beyond `suspected`.

## Scope

1. Keep JSX text out of JavaScript comment parsing while preserving expressions and tag attributes.
2. Follow CPython's raw-string quote handling closely enough for common valid regular expressions.
3. Separate an original report's byte-integrity SHA-256 from a reproducible semantic observation
   digest for the five-project v0.5.0 review.
4. Isolate the local TLS fixture from an inherited `SSL_CERT_FILE` trust configuration.
5. Publish a signed v0.5.1 release, verify its public assets and provenance, update the verified
   installer trust chain, and move `v1` only after its consumer workflow passes.

## Phase record

### P0 - completed

- JSX text containing `skills/*.yaml` reproduced `unterminated_block_comment`.
- A CPython-valid raw regular-expression string reproduced `unbalanced_python_delimiter`.
- The documented full-report SHA comparison was confirmed non-reproducible because direct audits
  create a random ephemeral subject. The audit report's absolute-path root-cause claim was rejected.
- The reported enterprise-CA failure was not reproduced locally, including with
  `SSL_CERT_FILE=/dev/null`; inherited trust state remains a low-cost isolation fix, not a confirmed
  product failure.
- The existing two-stage signed release, post-publication trust-anchor and `v1` promotion process is
  retained.

### P1 - completed

- JS/TS tokenization now treats JSX child text separately from JavaScript code while returning to
  code for tag attributes, nested JSX and brace expressions. Plain `skills/*.yaml` and
  `src/*.tsx` text no longer starts a block comment.
- Python tokenization now consumes the character after a backslash for raw and non-raw strings,
  matching CPython's quote-termination behavior for the reproduced valid raw regular expression.
- The ordinary-project evidence now records a semantic digest over schema version, ruleset digest,
  state summary and sorted finding ID/state pairs. `--report <project-id> <report.json>` verifies a
  reproduction without comparing its random ephemeral subject.
- The TLS fixture removes inherited `SSL_CERT_FILE` while setting its own `CURL_CA_BUNDLE`.
- Focused JS/TS, Python, TLS and case-journey tests passed. The case test proves matching semantics
  pass and a changed finding state fails.
