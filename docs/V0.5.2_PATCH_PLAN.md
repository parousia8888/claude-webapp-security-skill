# v0.5.2 patch plan

Status: completed

Web App Security Skill v0.5.2 is a focused correctness patch for independently reproduced v0.5.1
defects. It does not add detection rules, change finding/report schemas, widen active network
behavior or promote syntax matches beyond `suspected`.

## Scope

1. Render v3 state/severity summaries as structured counts in Markdown and HTML.
2. Recognize an applicable root `pnpm-lock.yaml` through bounded `pnpm-workspace.yaml` patterns and
   fail closed when workspace evidence cannot be interpreted.
3. Preserve JS/TS source coverage across nested templates and TSX brace expressions while scanning
   executable template expressions.
4. Treat a unique path-only finding move as unchanged and leave ambiguous duplicate moves
   unreconciled.
5. Publish a signed v0.5.2 release, verify its public assets and provenance, update the verified
   installer trust chain, and move `v1` only after its consumer workflow passes.

## Phase record

### P0 - completed

- Reproductions covered `[object Object]` in v3 Markdown/HTML summaries, pnpm-only workspaces marked
  as confirmed missing lockfiles, nested SSR/TSX templates producing partial coverage, and a pure
  path rename producing `fixed + new` with a successful retest exit.
- The existing evidence-state definitions remain intact. In particular, the release does not
  redefine file-local facts as `confirmed` or perform a broader rule reclassification.
- The established signed tag, reproducible artifact, post-publication trust-anchor and guarded
  `v1` promotion process remains the release contract.

### P1 - completed

- v3 summaries now traverse `byState[state].total` and `bySeverity`; golden Markdown and HTML
  assertions reject object coercion and zero-count state output.
- The lockfile check parses bounded pnpm package lists, includes and exclusions; malformed or
  unreadable workspace metadata is coverage uncertainty and cannot yield a confirmed absence.
- The JS/TS tokenizer tracks nested template/expression depth, retains TSX brace depth and continues
  scanning dangerous constructs inside template expressions.
- Retest comparison pairs only unique path-independent movement fingerprints. A moved condition is
  unchanged with `condition_moved`; ambiguous duplicates stay `new + fixed`.
- All 38 repository test files, lint, diff checks and Skill Creator validation passed before release
  version alignment. The final TSX brace-depth micro-fix also passed its focused regression and
  syntax check.
