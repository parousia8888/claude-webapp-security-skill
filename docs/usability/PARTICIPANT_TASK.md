# First-use participant task

Use only the supplied clean-room project. Do not open or share a personal or work repository.

1. From the repository README, use the entry path assigned for this session and show that Web App
   Security Skill is available.
2. Start the supplied project, run a source/local audit and locate the first report.
3. Explain what confirmed, suspected, unknown and not_applicable mean in the report. Say specifically
   whether a suspected result is already a confirmed vulnerability.
4. Inspect the proposed patch. Identify one way it could affect normal product behavior, then decide
   whether you would apply it with review, need help or would not apply it.
5. Apply only the documented fixture change and run a retest against the first report. Explain which
   check tests the security condition and which check tests normal product behavior.

You may stop at any time. Do not paste secrets, source code, repository links or terminal logs into
the session record. The facilitator may clarify the task wording but should not give the command or
interpret the report for you.
